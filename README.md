# Easy Button Color

## English

> Colors native action bar buttons by state: gray = on cooldown, blue = not enough resources, red = out of range.

- Gray when the ability is on cooldown.
- Blue when you do not have enough resources (mana / energy / rage / ...).
- Red when the target is out of range.
- Built for Blizzard's native action bars, and keeps working during combat.

## 简体中文

> 按状态给原生动作条按钮着色：灰色 = 冷却中，蓝色 = 资源不足，红色 = 超出范围。

- 技能冷却中变灰。
- 资源不足（法力 / 能量 / 怒气等）时变蓝。
- 目标超出射程时变红。
- 为暴雪原生动作条设计，战斗中同样生效。

## 繁體中文

> 依按鈕狀態為原生快捷列著色：灰色代表冷卻中、藍色代表資源不足、紅色代表距離過遠。

- 技能冷卻時變灰。
- 法力 / 能量 / 怒氣等資源不足時變藍。
- 目標距離過遠時變紅。
- 專為暴雪原生快捷列設計，戰鬥中同樣有效。
